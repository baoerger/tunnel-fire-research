# 闭合拟合框架软件验证报告

状态：**候选拟合软件完成；最终闭合变量、公式、系数和预测区间等待真实开发数据库。**

`src/closure_models.py` 对四个输出采用统一物理约束：

- `Pe_e = Fr*softplus(G_Pe)`；
- `Da_e = softplus(G_Da)+epsilon`；
- `Pi_S = Q_c_star*softplus(G_S)`；
- `delta_p/H = Fr*softplus(G_delta)`。

软件候选包括幂律潜变量、受限非线性基、二阶响应面和加性平滑基。它们共享同一输入/输出合同和完整工况分组交叉验证，避免把同一物理工况的派生样本分到训练与验证两侧。

两阶段接口先从逐工况参数拟合闭合，再用完整温度曲线对闭合系数做受约束坐标微调；测试保证第二阶段损失不高于第一阶段。工况 Bootstrap 以完整 `case_id` 为抽样单位，输出固定评价点的预测区间。受限符号表达式只允许低复杂度算术、`log1p/sqrt/softplus`、绝对值不超过 3 的常数幂，并在研究域逐点检查非有限值、除零和定义域错误。

当前测试数据由同一闭合结构合成，只证明接口、约束和数据隔离正确。不得据此选择幂律、非线性、响应面、GAM 或符号公式；真实候选比较必须使用 50 组开发工况的分组交叉验证，简单模型与复杂模型精度接近时优先简单模型，12 组独立测试不得参与选择。
