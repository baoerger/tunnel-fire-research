# 直接反演置信区间软件验证报告

状态：**A/B 类区间框架完成；真实精度、覆盖率和阶段五验收等待正式闭合、噪声统计与独立测试。**

## 已实现方法

- 在 `η=[log Q, x_f/H]` 空间对相关高斯负对数似然作中心差分 Hessian，并仅在 Hessian 正定时输出局部正态区间；Q 区间经指数变换回 MW，位置区间经 H 变换回 m。
- 对 Q—位置 `χ²` 网格分别取单参数剖面，默认使用已知噪声下 1 自由度 95% 阈值 `Δχ²=3.8414588`；同时报告区间是否碰到网格边界。
- 用指数空间协方差的 Cholesky 因子生成可复现的相关观测扰动。
- 使用与相关协方差一致的目标函数执行粗搜、多初值局部细化，并对拟合温度作参数化观测噪声 Bootstrap，输出参数百分位区间。
- Hessian、目标剖面、相关直接反演和 Bootstrap 均继承适用域分级。元数据
  缺失或几何/网格/测点越出核心域时仍可输出探索性区间，但不能把这些区间
  当作 100 m 核心域的正式覆盖率证据。

局部正态、剖面和参数化 Bootstrap 是互补的近似方法。正式研究时须报告方法差异、边界命中、剖面网格分辨率和 Bootstrap 收敛性，不能只择取最窄区间。

## 合成软件证据

分析脚本：`阶段五/src/confidence_intervals.py`；测试：`阶段五/tests/test_confidence_intervals.py`。输入测点来自 `阶段一/07_温度测点与输出规范/sensor_layout.csv`，正向观测来自合成常数潜变量闭合，不含 FDS 或试验数据。

输出文件：

- `synthetic_local_ci_scaling.csv`：4/8/12/16 点与 1/2/4 °C 假设噪声下的局部区间宽度；
- `synthetic_profile_ci.csv`、`synthetic_profile_ci.svg`：Q/位置剖面阈值与区间；
- `synthetic_parameter_bootstrap.csv`、`synthetic_bootstrap_summary.csv`：40 次相关噪声参数 Bootstrap。

确定性合成结果中，同一嵌套布局增加传感器时局部区间不增，噪声从 1 增至 2、4 °C 时 Q 与位置区间均增宽；目标面最小值位于生成真值，剖面没有碰到所给网格边界。这些结果只验证软件的方向性和接口。全部表均标记 `SYNTHETIC_SOFTWARE_TEST_NOT_SCIENTIFIC_EVIDENCE` 和 `SOFTWARE_ONLY_NO_COVERAGE_OR_REAL_PRECISION_CLAIM`，不得据此报告真实覆盖率。

## 正式分析依赖

正式区间必须等待阶段三给出稳态波动、重复种子离散与空间相关长度，阶段四固定真实闭合和模型不确定性；开发集用于选择方法、步长、网格和 Bootstrap 次数，12 组独立测试只在设置冻结后评价覆盖与误差。当前框架尚不能通过阶段五进入门。
