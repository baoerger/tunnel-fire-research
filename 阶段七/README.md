# 阶段七：鲁棒性与论文总结

当前完成 7.1 鲁棒性工具、7.2 外部观测转换、7.3 不确定性汇总与非诊断性异常提示，以及 7.4 瞬态候选和论文/验收追溯模板。所有数值检查仍是合成软件证据；真实外部反演结果保持空白。现有三组试验位于 100 m 核心域之外，可用于端到端外部泛化评价，但不能替代核心域独立验证；瞬态候选未生成或提交 FDS 输入。

- `src/robustness.py`：温度噪声、随机缺测、恒定偏置、空间漂移、测点位置误差；留功率/风速/尺寸/位置区间；统一鲁棒性矩阵。
- `tests/test_robustness.py`：确定性、源样本不变、精确偏置/漂移、最低有效数、完整工况隔离、矩阵完整性和证据标签测试。
- `src/external_observations.py`：阶段一三组公开试验的观测、测点映射和已知参数转换；显式区分热电偶观测与主体气体温度目标。
- `tests/test_external_observations.py`：工况/测点数量、温度类型、来源、不确定性和等待状态合同。
- `src/uncertainty_anomaly.py`：正向公式/直接反演/网络三层不确定性来源、空间残差、开发分位阈值、模型失配提示和 100 m 条件域/OOD 标志。
- `04_论文与验收/t2_transient_candidates.csv`：慢/中/快三种候选增长率 × 20/60 MW 的 6 个可选工况；全部为 `CANDIDATE_ONLY_WAITING_STAGE6_GATE`，`fds_input_path` 为空。
- `04_论文与验收/验收复核表.csv`：附 A 的 11 条预设验收判据，当前全部为 `NOT_EVALUATED`。
- `04_论文与验收/创新点与预期成果证据表.csv`：4 项创新和 12 项预期成果的证据要求、当前产物、允许措辞和等待状态。
- `04_论文与验收/论文图表清单.csv`：12 幅图、3 张表的预定数据源、子集、版本、脚本、指标、产物路径和证据路径。
- `04_论文与验收/论文方法与数据流模板.md`、`论文结果表模板.md`：方法章节、决策门数据流、追溯块和保持空白的正式结果表。
- `01_鲁棒性工具/`：合成矩阵、留区间分组和软件验证报告。
- `02_外部端到端反演/`：三组真实观测模型输入 JSONL、空白等待评价表和转换说明。
- `03_不确定性与异常提示/`：合成不确定性表、异常检查、空间残差 SVG 和说明。

运行：

```bash
uv run --python 3.12 python -m unittest discover -s 阶段七/tests -v
uv run --python 3.12 python 阶段七/src/robustness.py
uv run --python 3.12 python 阶段七/src/external_observations.py
uv run --python 3.12 python 阶段七/src/uncertainty_anomaly.py
```

`tests/test_paper_materials.py` 额外校验 6 个候选组合与 t² 到峰值时间、11 条验收判据、4+12 项证据登记、表格追溯字段和阶段七零 `.fds`。扰动幅值和留出区间须在阶段三开发数据上固定；独立测试只在全部设置冻结后释放。外部试验均为热电偶观测，须先确定响应模型或显式模型差异处理，并等待正式模型固定后执行端到端外部泛化评价。三组几何和网格均越出 V2 核心域，因此其误差应单列为域外泛化结果，不作为核心域正式精度门；这不妨碍计算、比较和讨论。可选瞬态只有在阶段六四模型对照完成后才能决定是否正式生成和运行。

论文和工程输出必须同时报告 `protocol_version=100M_CONDITIONAL_DOMAIN_V2`、
几何/网格/测量区、域删失类别和适用域状态。域外结果标为
`OOD_EXPLORATORY` 并单独报告其泛化误差；元数据不足时标为
`APPLICABILITY_UNDETERMINED`。两类结果都允许研究，但不与核心域正式指标合并。
