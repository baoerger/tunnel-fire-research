# 随机种子重复说明

阶段二正式温升删失阈值需要把单次稳态时间波动与独立 LES 重复之间的离散
分开。现有 12 组各只有一次运行，分块 Bootstrap 不能替代独立随机种子重复。

FDS 官方标签 `FDS-6.9.1`（commit `889da6ae08d08dae680f7c0d8de66a3ad1c65375`）
的 `FDS_User_Guide.tex` 明确说明在 `MISC` 行使用 `RND_SEED` 改变预定义随机
序列；同标签源码 `Source/read.f90` 将 `RND_SEED` 读入 MISC namelist，
`Source/init.f90` 将其加到各 MESH 的预定义种子。该依据只确认官方语法，
正式可用性仍须由外部 FDS 6.9.1 实跑检查，不写成已实跑兼容性结论。

`pilot_seed_repeat_cases.csv` 选择两个已有基准：近临界
`pilot_06_q40_r100_d45` 和高功率强风 `pilot_11_q100_r160_d70`。原结果作为
默认 `RND_SEED=0` 基准，新增一次非零种子重复；除 CHID 和 RND_SEED 外，
Q、U、Df、几何、网格、测点、输出和时长保持一致。

```bash
  --csv 阶段二/01_先导工况设计/pilot_seed_repeat_cases.csv \
  --outdir 阶段一/outputs/pilot_seed_inputs
```

外部平台先检查输入解析、时间推进、非零 HRR 和 `RND_SEED` 日志记录，再完成
300 s 正式运行。每组至少回传实际 `.fds`、`.out`、`_devc.csv` 和 `_hrr.csv`；
建议保留 `.end`、`.smv` 和温度/速度切片。结果放到
`阶段一/outputs/runs/<chid>/`，先经 `check_fds_results.py`，再由阶段三批量
后处理汇总同一 `parent_chid` 的时间波动与重复均值离散。
