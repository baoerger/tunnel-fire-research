# 解析结构软件验证报告

状态：**软件框架、合成测试和 FDS 6.9.1 真实先导质量检查已完成；不再等待版本升级，但正式阈值证据缺失且候选结构仅 4/12 通过，不能通过结构判伪门。**

`src/transport_model.py` 已实现：

- 点源分段指数温度核及 `Pe_e=kappa_u-kappa_d`、`Da_e=kappa_u*kappa_d`；
- 单一高斯有限源与点源 Green 核的数值卷积；
- 以点源远场参数为初值，对有限源的源中心、双侧衰减率和源强作确定性受限坐标优化，避免把点源参数原样套用后作不公平比较；
- 约束共同峰值的 `delta_Tp/x_p/k_u/k_d` 拟合；
- 以完整物理工况为组的近场排除候选评价；
- 拟合区间扰动和参数最大相对变化统计；
- 明确标记的合成参数恢复输出 `synthetic_software_check.csv`。

合成检查只验证代码能恢复已知参数、无风对称极限、远场衰减和有限源零宽度极限。它不证明真实 FDS 曲线服从分段指数，也不确定 0.4H 是最终近场范围。

真实结果返回后须按顺序记录：原始 CHID/时段 → 质量检查 → 时间平均剖面 → 近场候选分组得分 → 拟合区间扰动 → 点源/有限源交叉验证 → 残差图。至少约 75% 先导工况满足结构且主要衰减参数区间扰动原则上不超过约 20%，才可进入数据库扩展决策。
