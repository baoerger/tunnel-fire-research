# 旧资产复用与作废边界

## 1. 迁移原则

旧路线不删除，以保留研究可追溯性；新路线只复用与“无风正向公式发现”物理含义一致、且能通过新合同验证的通用资产。复用软件不等于复用旧科学结论。

## 2. 可直接复用的软件资产

| 旧路径 | 可复用内容 | 新路线用途 |
|---|---|---|
| `阶段一/src/generate_fds_case.py` | 参数化几何、两端 `OPEN` 的 `U=0` 分支、燃烧器离散面积闭合、多 MESH、FDS 输出 | 新无风 `.fds` 的唯一生成入口；需增加密集对称测点配置 |
| `阶段一/src/tunnel_config.py` | 燃料、材料、环境温度、FDS 量名、输出频率 | 第一版固定物性；几何不再固定为单一 `H/W/L` |
| `阶段一/src/fds_io.py` | DEVC/HRR CSV 双表头读取与单位归一化 | 读取所有新工况结果 |
| `阶段一/src/check_fds_results.py` | 完整性、版本、日志、HRR 和关键列检查 | 新结果质量硬门 |
| `阶段一/src/check_convection_ratio.py` | 从 `HRR` 与 `Q_RADI` 计算火源对流份额 | 构造 `Q_c` 与 `Q_c*` |
| `阶段一/src/quasi_steady_detect.py` | 准稳态候选窗口 | 新工况时间窗识别的起点 |
| `阶段一/src/time_average_bootstrap.py` | 时间平均和分块 Bootstrap | 温度、峰值和对称性不确定性 |
| `阶段一/src/extract_cross_section_integrals.py` | 场积分框架 | 需要全场物理解释时条件复用 |

复用前必须运行相关旧测试，并新增无风合同测试。若通用源需要扩展，应保持原参数默认行为不变。

## 3. 仅可作方法参考的资产

| 旧路径 | 可参考内容 | 禁止事项 |
|---|---|---|
| `阶段二/src/evaluate_stretched_exponential.py` | 拉伸指数拟合与留一选择思路 | 不直接使用旧上下游、有风数据结构或旧科研结论 |
| `阶段二/src/censoring_peak.py` | 连续峰值、平台宽度、Bootstrap 思路 | 不沿用强风删失类别作为无风模型结构 |
| `阶段四/src/closure_models.py` | 正性约束、分组交叉验证、复杂度控制 | 不沿用 `Pe/Da/Pi_S/delta_p` 作为新方案预设闭合对象 |
| `阶段四/src/empirical_baselines.py` | Li 最大温升基准实现 | 必须再次核对单位；Kurioka 的 `U=0` 奇点分支不适用 |
| `阶段四/src/forward_validation.py` | 指标汇总框架 | 不沿用旧独立测试或旧模型排名 |

若参考代码被采用，应在本目录建立新接口和新测试，不把旧输出文件重命名成新研究结果。

## 4. 明确作废的当前执行内容

以下内容自 2026-08-14 起不得继续作为当前研究任务：

- 原 68 组有风开发/测试/偏移工况配额；
- 按弱风、临界风和强风划分工况；
- 上下游非对称 `k_u/k_d` 作为主体温度核；
- 强风上游删失作为主体研究问题；
- 火源功率与位置直接反演；
- Fisher 传感器布局优化；
- 集合编码器和可微物理解码网络；
- 旧阶段五至阶段七的验收指标；
- 原 12 个有风独立测试作为新方案封存测试；
- 将旧外部有风试验称为无风公式验证。

## 5. 历史数据的允许用途

旧数据只允许用于：

1. 回归测试 CSV 读取、单位归一化和日志检查软件；
2. 演示绘图或软件接口时作为明确标注的历史/合成输入；
3. 在论文研究历程中解释为什么转向无风专项；
4. 与未来无风结论进行定性背景比较，但不进入拟合和正式统计。

任何复用表都必须保留原 `CHID`、FDS 版本、来源路径和 `HISTORICAL_WIND_STUDY_NOT_NO_WIND_EVIDENCE` 标记。

## 6. 新旧目录边界

- `阶段一/`：共享 FDS 基础设施和历史验证资产；
- `阶段二/` 至 `阶段七/`：旧有风路线历史资产，冻结；
- `无风公式重发现/`：全部新设计、代码、工况注册、结果、模型和论文证据；
- 根目录旧方案文件：历史来源，不再更新；
- 根目录 `CLAUDE.md`：继续约束所有 FDS 工作，不因路线切换而失效。
