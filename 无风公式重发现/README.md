# 无风公式重发现

> 本目录是项目自 2026-08-14 起的**唯一当前研究入口**。

## 当前目标

研究无机械纵向风条件下，已知火源功率、位置和隧道参数时的顶棚中心线纵向温度分布，形成经过 FDS 6.9.1、封存工况和外部试验验证的显式公式。

旧“纵向通风—火源参数反演—物理解码网络”路线已经作废。旧阶段二至阶段七的代码、文档和结果只作历史资产，不再决定当前工况、公式或论文结论。

## 执行纪律

1. 新代码和新结果优先写入本目录，避免继续扩展旧有风阶段目录。
2. 通用工具从旧阶段一原位导入，不复制源码；需要修改时先保证旧合同测试仍通过。
3. 新 `.fds` 仍必须由共享生成器生成，禁止长期手改。
4. 首批工况在无风网格、洞口、随机性、密集测点和目标版本短试算通过前，只能用于静态设计检查。
5. 现有有风 FDS 结果、旧 68 组工况和旧封存测试不得进入新模型训练、选择或评价。

## 当前最近任务

1. 核对 Oka、Kashef、Li–Lei–Ingason 等原始论文公式，优先验证 Word 的 `p_2≈1/2`；
