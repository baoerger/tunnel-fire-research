## 4. 阶段三：无风前置验证

### 4.1 网格

- [ ] 选择低/中功率代表工况。
- [ ] 每个工况至少设置粗、中、细三档网格。
- [ ] 比较 `Delta T_max`、`x_m`、`A_global`、归一化曲线、候选 `K/n` 和转换点。
- [ ] 记录 `D*/dx` 与核心量变化，不用单一网格指标替代目标量收敛。
- [ ] 若资源约束选工作网格，明确“不等于网格收敛”。

### 4.2 洞口与域长

- [ ] 对一个代表工况比较至少两种 `L/H`。
- [ ] 检查峰值、对称性、远场衰减和转换点是否受洞口影响。
- [ ] 根据结果冻结主体 `L/H` 和有效测量区。

### 4.3 随机性

- [ ] 低功率和高功率各至少一个非零随机种子重复。
- [ ] 计算点对点、峰值、对称性和曲线参数的随机波动。
- [ ] 用重复结果确定对称阈值和最小可解释模型改善。

决策门：网格、洞口或随机性尚能改变模型结构时，不得启动 16 个正式判伪工况。

### 5.2 数据处理

### 5.3 第一轮模型判伪

- [ ] 盲拟合 `Delta T_max=C Q^a/H_eff^b`。
- [ ] 比较自由指数与 `a=2/3,b=5/3` 基准。
- [ ] 分别拟合固定 `W/H` 主块与固定 `W` 诊断块，量化 DOE 对高度指数的影响。
- [ ] 逐工况拟合普通指数和拉伸指数。
- [ ] 只有出现重复残差时才识别变化点和三区域模型。

判伪停止条件：对称性、最大温升尺度或温度曲线结构不能稳定复现时，先修改物理设计，不直接扩大数据库。
