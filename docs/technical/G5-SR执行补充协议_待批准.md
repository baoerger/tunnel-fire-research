## 本稿封住的执行缺口

### 1. shape 必须先走 `xi-only`

一个完整任务族由 180 个内层搜索、45 个外层重搜和 20 个全开发集种子组成，共 245 个 trial。第一批固定为：

- peak `q,d`：245；
- shape `xi-only`：245；
- 初始合计：490。

只有以下任一条件满足，才允许追加 shape `xi,q,d` 的 245 个 trial，因而主搜索绝对上限为 735：

1. `xi-only` 的折外标准化残差对 `log(q)` 或 `log(d)` 触发现有系统残差门：以 `parent_case_id` 聚类 Bootstrap，Holm 校正后的区间不含 0，且跨完整设计范围的标准化效应绝对值不小于 0.25；
2. `xi-only` 未通过已经批准的绝对 shape 门。

若未触发，禁止为了“再看看”运行 `xi,q,d`。若触发，含 `q/d` 的形状式只有相对最佳 `xi-only` 和 `A0` **分别**通过既有 `materially_better` 门，并继续通过绝对门、系统残差门、稳定性门和连续域物理门，才可保留。

触发统计固定使用 2,000 次 `parent_case_id` 聚类 Bootstrap 和种子 `2026082601`。两侧 p 值采用带 `+1` 修正的 Bootstrap 符号概率并截断到 1，随后对 `log(q)`、`log(d)`、`xf_actual_m-50`、`right_minus_left` 四项按上述顺序执行 Holm step-down；只有前两项可以触发 shape 扩展。标准化效应定义为父组平均标准化残差的 OLS 斜率乘开发集该预测量的完整范围。九个外层折必须各有且仅有一条不读取本折留出数据而选定的 `xi-only` 结构及其折外预测；任一折缺失或多选时写入 `SHAPE_EXPANSION_DECISION_NOT_EVALUABLE` 并停止，不能把“不可评价”解释为自动触发。

每个 trial 的 8 个种群、每群 64、最多 300 轮、最多 50,000 次候选评价和最多 900 s 均为独立上限，任一先到即停。失败、超时、中断和无候选种子保留在分母中，不补种子。弱约束消融只对同一原始候选池后验去除指定物理过滤并重新评价，不再启动一轮随机搜索，因此不增加上述 trial 数。

### 2. 选择、稳定性和等价族必须唯一可复现

- 外层留出父组不得进入候选选择或平局裁决。
- 冻结主指标数值相同时，依次按规范化复杂度、自由常数数、分组中位误差、分组 90% 分位误差、规范表达式 UTF-8 字节序及模板 SHA-256 裁决。
- 稳定性分子只统计每个外层折或全开发集种子最终选中的一条结构；“某条式子曾出现在 Pareto 候选池”不计稳定性命中。失败 trial 记 0 且仍留在分母。
- 预测等价不是传递关系。禁止用并查集/连通分量把 `A≈B、B≈C、A≉C` 合并为一族。本稿采用固定排序的 complete-link leader：新成员只有与族内每个已有成员都同时满足 RMS 1% 和最大差 3% 门时才可加入。

### 3. 常数统一复估参数仍属于待批准建议

本稿建议从引擎 AST 提取常数模板，A0 与 SR 候选使用同一 `L-BFGS-B` 全似然复估器；普通无量纲系数边界为 `[-100,100]`，严格正尺度为 `[1e-6,100]`，自由指数沿用 `[-3,3]`。每次拟合共 32 个确定性起点：引擎初值或区间中点 1 个，加 31 个由模板、阶段、折和搜索种子派生种子的 Sobol 起点。

无有效起点、最佳盆地不能由至少两个起点复现，或最终参数触边时，候选不得进入冻结。不得看到结果后扩边界、换优化器或人工修复；如需改变，必须先发布并批准新版补充协议。

这些数值是**草案建议，不是既成批准事实**。用户批准前，实现代码不得据此运行正式搜索。
