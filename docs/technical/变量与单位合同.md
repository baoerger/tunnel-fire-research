# 无风公式重发现变量与单位合同

> 状态：执行接口合同 v1.0-draft（2026-08-18，待 G0 外部环境审计后冻结）  
> 适用范围：无机械纵向风、两端开放、单火源的 FDS 工况及其后处理  
> 约束：FDS 原始 CSV 的单位以文件单位行为准；进入分析表前必须归一化

## 1. 命名与文件层级

拟合和统计不得直接依赖含义不明的列名。后续数据至少拆成四张表：

| 文件 | 一行代表 | 主键 |
|---|---|---|
| `case_master.csv` | 一个完整物理工况 | `physical_case_id` |
| `job_attempts.csv` | 一次 FDS 进程启动 | `job_attempt_id` |
| `curve_points.csv` | 一条逻辑仿真轨迹、一个时间窗、一个纵向测点 | `run_chid,window_id,x_coord_m` |
| `case_metrics.csv` | 一条逻辑仿真轨迹的准稳态派生量 | `run_chid,window_id` |
| `case_fit_parameters.csv` | 一个工况的一类曲线模型 | `physical_case_id,window_id,model_id` |

同一 `physical_case_id` 的测点、时间窗和随机种子派生样本不得跨开发集与锁箱；同一 `parent_case_id` 默认处于同一交叉验证折。`run_chid` 是 FDS `CHID`，一个 `run_chid` 只能对应一个 `run_core_sha256`；每次实际启动另建永不复用的 `job_attempt_id`。

## 2. 工况设计与原始输入字段

| CSV 字段 | 数学量/含义 | 单位 | 类型 | 必填 | 来源 |
|---|---|---:|---|---|---|
| `parent_case_id` | 同一 Q/尺寸下的中心与偏移父组 | — | string | 是 | 工况设计 CSV |
| `physical_case_id` | 唯一 Q、尺寸与位置物理条件 | — | string | 是 | 工况设计 CSV |

## 3. 壁面属性字段

材料标签只用于追踪，模型输入必须保留原始属性。

| CSV 字段 | 数学量/含义 | 单位 | 类型 | 必填层级 | 来源 |
|---|---|---:|---|---|---|
| `wall_material_id` | 材料追踪标识 | — | string | `case_master` 是 | `tunnel_config.py`/FDS 输入 |
| `wall_k_W_m_K` | `k_w`，导热系数 | W/(m·K) | float | `case_master` 是 | FDS `MATL CONDUCTIVITY` |
| `wall_rho_kg_m3` | `rho_w`，密度 | kg/m³ | float | `case_master` 是 | FDS `MATL DENSITY` |
| `wall_cp_kJ_kg_K` | FDS 输入比热 | kJ/(kg·K) | float | 生成审计是 | FDS `MATL SPECIFIC_HEAT` |
| `wall_cp_J_kg_K` | `c_w`，分析比热 | J/(kg·K) | float | `case_master` 是 | 上一字段乘 `1000` |
| `wall_thickness_m` | `delta_w`，壁层厚度 | m | float | `case_master` 是 | FDS `SURF THICKNESS` |
| `wall_emissivity` | `epsilon_w`，发射率 | 1 | float | `case_master` 是 | FDS `SURF EMISSIVITY` |

不得只保存 `wall=concrete`，也不得只保存派生 `Pi_w`。若为多层壁面，当前单层合同停止适用，需把层序和每层属性另表展开。

## 4. FDS 原始输出字段

| 标准分析字段 | FDS 原始列/模式 | 分析单位 | 类型 | 必填 | 来源文件 |
|---|---|---:|---|---|---|
| `time_s` | `Time` | s | float | 是 | `<CHID>_devc.csv`/`_hrr.csv` |
| `temp_C` | `T_*` 温度设备 | °C | float | 是 | `<CHID>_devc.csv` |
| `u_ms` | `U_*`，量名 `U-VELOCITY` | m/s | float | 质量诊断是 | `<CHID>_devc.csv` |
| `hrr_total_kW` | `HRR_tot` 或 `HRR` | kW | float | 是 | `_devc.csv`/`_hrr.csv` |
| `q_radi_kW` | `Q_RADI` | kW | float | 是 | `<CHID>_hrr.csv` |
| `wall_heat_flux_kW_m2` | `Qw_*` | kW/m² | float | 代表工况是 | `<CHID>_devc.csv` |
| `x_coord_m` | 从设备 ID/注册表解析的测点坐标 | m | float | 温度点是 | 测点清单/生成记录 |
| `y_coord_m` | 从设备 ID/注册表解析的测点坐标 | m | float | 温度点是 | 测点清单/生成记录 |
| `z_coord_m` | 从设备 ID/注册表解析的测点坐标 | m | float | 温度点是 | 测点清单/生成记录 |

读取时必须识别 FDS 的单位行和字段名行，不得仅凭列名猜测单位。`Q_CONV` 不是本研究的火源对流 HRR；火源对流功率统一由 `Qc_kW=hrr_total_kW+q_radi_kW` 计算。

## 5. 派生字段及定义

| 标准字段 | 定义 | 单位 | 类型 | 必填层级 |
|---|---|---:|---|---|
| `T0_K` | `T_ambient_C+273.15` | K | float | `case_master` |
| `H_eff_m` | `H-z_fire` | m | float | `case_master` |
| `L_minus_m` | `xf_actual_m` | m | float | `case_master` |
| `L_plus_m` | `L-xf_actual_m` | m | float | `case_master` |
| `lambda_minus` | `L_minus_m/H_eff_m` | 1 | float | `case_master` |
| `lambda_plus` | `L_plus_m/H_eff_m` | 1 | float | `case_master` |
| `eta_y` | `2*abs(y_fire-W/2)/W` | 1 | float | `case_master` |
| `beta` | `W/(2H_eff_m)` | 1 | float | `case_master` |
| `AR` | `W/H_eff_m` | 1 | float | `case_master` |
| `b_f_m` | `sqrt(Af/pi)` | m | float | `case_master` |
| `phi_f` | `b_f_m/H_eff_m` | 1 | float | `case_master` |
| `Qc_kW` | `HRR+Q_RADI` | kW | float | `case_metrics` |
| `Q_star` | `Q/(rho0 cp T0 sqrt(g) H_eff^(5/2))` | 1 | float | `case_metrics` |
| `Qc_star` | 同上，以 `Qc` 替换 `Q` | 1 | float | `case_metrics` |
| `D_star_m` | `[Q/(rho0 cp T0 sqrt(g))]^(2/5)`，`Q` 用 W | m | float | 网格审查 |
| `Dstar_over_dx` | `D_star_m/dx` | 1 | float | 网格审查 |
| `wall_alpha_m2_s` | `k_w/(rho_w c_w)` | m²/s | float | 材料扩展 |
| `wall_effusivity` | `sqrt(k_w rho_w c_w)` | J/(m²·K·s^0.5) | float | 材料扩展 |
| `Pi_e` | 见主方案 3.7 | 1 | float | 材料扩展 |
| `Fo_b` | 见主方案 3.7 | 1 | float | 材料扩展 |
| `deltaT_C` | `temp_C-T_ambient_C` | K | float | `curve_points` |
| `xi` | `abs(x_coord_m-xf_actual_m)/H_eff_m` | 1 | float | `curve_points` |
| `xi_peak` | `abs(x_coord_m-x_peak_m)/H_eff_m` | 1 | float | 仅诊断 |
| `Theta` | `deltaT_C/deltaT_max_K` | 1 | float | `curve_points` |

`Q_star` 中的 `Q` 在计算时统一为 W，`rho0` 与 `cp` 必须记录取值和来源。温差的数值可用 K 或 °C，但字段统一写作 K/C 的温差含义，不得与绝对温度混用。

## 6. 工况级结果字段

`case_metrics.csv` 至少包含：

| 字段 | 单位/取值 | 必填 |
|---|---:|---|
| `physical_case_id,run_chid,window_id` | 标识 | 是 |
| `window_start_s,window_end_s` | s | 是 |
| `quasi_steady_status` | enum | 是 |
| `deltaT_max_K` | K | 是 |
| `x_peak_m` | m | 是 |
| `peak_plateau_width_m` | m | 是 |
| `A_global` | 1 | 是 |
| `symmetry_status` | enum | 是 |
| `bootstrap_n,bootstrap_success_rate` | count/1 | 是 |
| `quality_status` | enum | 是 |
| `exclusion_reason` | string | 否 |

`case_fit_parameters.csv` 必须同时保存参数估计、标准误/置信区间、搜索边界、是否触界、拟合域、损失各分项和模型采用/否决理由。

## 7. 缺失、状态与精度规则

1. 缺失值写空并配套状态列，不使用 `0`、`-999` 或字符串 `NA` 冒充数值。
2. `status=DESIGN_ONLY_NOT_AUTHORIZED_FOR_FORMAL_RUN` 的工况不得出现在正式结果表。
3. `fds_version` 和 revision 只能从实际 `.out` 解析；未运行写空，不能用计划值冒充实跑值。
4. CSV 保存原始精度；表格展示时再舍入。坐标至少保存到能区分当前最细网格。
5. 每张分析表都要记录生成脚本版本、输入文件哈希和处理时间，确保从派生量追溯到原始 FDS 文件。
