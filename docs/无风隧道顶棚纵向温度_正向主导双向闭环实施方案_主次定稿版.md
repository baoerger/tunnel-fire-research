## 1. 研究问题与定位

### 1.1 研究对象

研究对象为水平矩形隧道中、无机械纵向来流条件下，单一准稳态火源驱动的顶棚中心线气体温升。

“无机械纵向风”指：

- 两端在相同环境条件下开放；
- 不设置入口速度、射流风机或机械排烟；
- 允许火羽流和两端开口产生浮力驱动的双向流；
- 正式判断依据是边界设置与无火背景速度场，不是把所有速度强制为零。

研究只在预注册的**有效高温域**内重发现最大温升与纵向衰减显式公式，并用冻结公式反演火源功率 \(Q\) 和纵向位置 \(x_f\)。域外数据只承担背景、洞口和异常质量控制。

### 1.2 调研结论与本版修改

结合 NIST FDS 文档、隧道顶棚温度研究及统计建模文献，原方案的主线成立：

\[
\boxed{
\text{可信 FDS}
\rightarrow
\text{有效域}
\rightarrow
\text{公式/结构重发现}
\rightarrow
\text{独立正向筛选}
\rightarrow
\text{直接反演}
\rightarrow
\text{独立 FDS 锁箱}
}
\]

需要修正的内容集中如下。

| 原方案问题 | 本版处置 |
|---|---|
| 把远场一维通道流作为第三段和创新点 | **删除远场温度研究、区域 III、第二转换点和远场参数**；域外只作 QC |
| 把发现全新普适公式作为成败条件 | 保留限定域内的公式/结构重发现，但不承诺得到跨尺度、机理上全新的普适方程 |
| 固定几何却拟合高度指数或宽高比规律 | 固定 \(100\times10\times5\ \mathrm m\) 隧道，只改变 \(Q,D_f,x_f\)；不识别高度指数或宽高比规律 |
| 用峰值归一化曲线直接作最终拟合 | 归一化只作诊断；最终拟合使用原始温升和真实全局坐标 |
| 先删除不对称工况再证明对称 | 对称性改为可证伪假设，失败工况不得因结论不理想而删除 |
| 同一开发数据完成拟合和反演后称“双向验证” | 只称开发集数值闭环；泛化能力由独立 FDS 锁箱评价，结论仍限定于本研究数值场景 |
| 两区式和虚拟原点提前写成主体 | 单区优先；两区和虚拟原点只有开发证据支持时才保留 |
| 把有限候选比较直接等同于符号回归发现，或把人工候选基准写成最终公式 | 现有 `M1_S1` 保留为不可变人工候选基准 `A0`；批准后的 G5-SR 形成 `A_SR` 或 `SR_NO_REPLACEMENT`，两种分支均在联合重拟合后生成唯一最终冻结 `A_active` |
| Fisher、网络篇幅与“可选”定位不符 | 第8章只保留备用科学合同；当前默认不实施，导师在开箱前明确要求时才激活，不作为论文成立条件 |

有效高温域显式温升公式及其跨工况闭合是正向主体。所谓“重发现”，是让数据在物理约束下识别功率尺度、火源尺寸依赖和空间形状，并在单区、拉伸指数和连续两区结构之间作可证伪选择；它不等于承诺得到无限尺度普适的新方程。当前有限候选 `M1_S1/A0` 已给出一条合格的人工候选基准；正式批准的受控符号回归负责审计是否存在同样简洁但更稳的遗漏结构，并形成最终 `A_active`，而不是保证产生更复杂的新公式。双向方法链用于证明公式既能正向解释温度，又保留了反演 \(Q,x_f\) 所需的信息，但反演不能挽救正向不合格的公式。

### 1.3 核心研究问题

1. 在无机械纵向风条件下，哪些顶棚测点构成可重复建模的有效高温域？
2. 固定几何下，最大温升的 \(Q\) 尺度及 \(D_f\) 依赖能否由数据稳定重发现？
3. 域内纵向形状支持平滑单区、拉伸指数，还是连续两区结构？
4. 偏移火源能否在洞口余量约束下近似视为坐标平移？
5. 冻结正向公式是否保留了足够信息，使 \(Q,x_f\) 可辨识？
6. 独立 FDS 锁箱能否支持公式与反演在未见完整工况上的泛化？

### 1.4 主体、可选项与排除项

**主体必做：**

- FDS 6.10.1 问题特定验证；
- 有效域、测温高度和火焰状态冻结；
- 最大温升闭合与纵向形状公式重发现；
- A0 人工候选比较、受约束物理辅助符号回归、完整过程报告和 `A_active` 最终正向冻结；
- \(Q,x_f\) 直接反演和可辨识性评价；
- 独立 FDS 锁箱评价。

**条件增强：**

- Fisher 传感器布局；
- 可微物理解码网络（当前 `G7_SKIPPED_NOT_REQUESTED`，仅导师触发）。

条件增强未激活不构成研究缺项或失败。若锁箱已经打开后才提出网络要求，必须发布新协议并建立新的未见网络锁箱，原锁箱不得再次承担网络确认性评价。

**不纳入主体：**

- 远场温度衰减规律；
- 机械纵向、横向或集中排烟；
- 多火源、移动火源和横向偏置二维定位；
- 任意瞬态 HRR 历程；
- 多燃料、多材料和无限尺度普适性；
- 未经分层的连续火焰撞顶与纯烟气顶棚射流统一公式。

## 2. 变量、观测量和适用域

本章是变量和适用域的唯一权威定义位置。正向、反演及可选模块均调用本章合同。

### 2.1 温升与测温高度

火源到顶棚的几何净高为：

\[
H_g=H-z_f.
\]

主体测温位置为：

\[
z_s=H-\epsilon_s H_g,
\qquad
0<\epsilon_s<1.
\]

\(\epsilon_s\) 由不进入公式拟合的竖向剖面先导和网格可比性共同确定，在主体工况前冻结。\(0.10\) 可作为初始候选，但不是预设真值。

主体观测量为气体温升：

\[
\Delta T(x,t)=T_g(x,z_s,t)-T_0,
\]

\[
\overline{\Delta T}(x)
=
\frac{1}{t_b-t_a}
\int_{t_a}^{t_b}\Delta T(x,t)\,dt.
\]

峰值诊断定义为：

\[
\Delta T_p
=
\max_{\xi\le\xi_h}\overline{\Delta T}(x),
\qquad
x_p
=
\operatorname*{arg\,max}_{\xi\le\xi_h}
\overline{\Delta T}(x).
\]

允许用预注册的局部插值评估网格峰值偏差，但最终公式仍拟合原始空间温升，不把平移到 \(x_p\) 后的归一化曲线当作独立数据。

\(T_0\) 在无量纲公式中使用 K；温差以 K 或摄氏度差表示时数值相同。准稳态窗口必须同时通过 HRR 和代表温度信号检查。

### 2.2 固定几何与主体变量

主体研究只使用现有水平矩形隧道，不新增高度、宽度或长度场景：

\[
L=100\ \mathrm m,
\qquad
W=10\ \mathrm m,
\qquad
H=5\ \mathrm m.
\]

主体火源位于地面，故 \(z_f=0\)、\(H_g=5\ \mathrm m\)、\(AR=W/H_g=2\)。\(H_g\) 和 \(AR\) 在本项目中是固定几何元数据，不是待识别变量；保留这些符号只为定义无量纲坐标、表述适用边界和与文献同口径比较。

主文只保留一套无量纲变量：

\[
\xi=\frac{|x-x_f|}{H_g},
\qquad
d=\frac{D_f}{H_g},
\qquad
AR=\frac{W}{H_g},
\]

\[
Q^*
=
\frac{Q}
{\rho_0c_pT_0\sqrt g\,H_g^{5/2}}.
\]

其中：

- \(Q\)：通过准稳态门后的实际平均总 HRR；
- \(D_f=\sqrt{4A_f/\pi}\)：按网格吸附后实际燃烧面积得到的等效直径；
- \(W,H,L\)：隧道宽度、高度和总长；
- \(x_f,z_f\)：火源纵向位置和高度；
- \(\rho_0,c_p,T_0\)：环境空气性质。

主体工况交叉改变 \(Q,D_f,x_f\)。因此可以研究固定几何内的功率尺度、火源尺寸效应、空间形状和位置平移，但不能从本数据库识别 \(H_g\) 指数、\(AR\) 效应或长度尺度律。

等效直径只适用于形状相似的紧凑火源。主体数据库固定火源形状、长宽比和朝向；若研究非相似矩形火源，必须增加独立形状变量，不能仅靠相同 \(D_f\) 合并。

`Q_requested`、`Df_requested` 只用于实现误差审计，不能替代实际值进入正式拟合。工况文件应保存：

- `Q_requested`、`Q_actual`；
- `Af_requested`、`Af_discrete`；
- `Df_requested`、`Df_discrete`；
- `HRRPUA` 和 `burner_bounds`。

火源至两端洞口的无量纲余量为：

\[
\lambda_-=\frac{x_f}{H_g},
\qquad
\lambda_+=\frac{L-x_f}{H_g}.
\]

有效对流功率代理量只作敏感性分析：

\[
Q_{c,\mathrm{proxy}}=HRR+Q_{\mathrm{RADI}}.
\]

`Q_RADI` 通常为负。该代理不等于真实火源对流 HRR，`_hrr.csv` 中的计算域 `Q_CONV` 也不能直接替代它。

若比较该代理版本，每一交叉验证折只能用训练工况估计必要的转换关系；验证和锁箱工况不得读取自身 `Q_RADI` 后再预测自身温度。

### 2.3 有效高温域与测点角色

正向公式的支持域为：

\[
0\le \xi\le \xi_h.
\]

\(\xi_h\) 由先导工况一次性冻结，判据至少包括：

1. 温升置信下界高于背景检测能力；
2. 网格和随机种子扰动下曲线稳定；
3. 固定 \(100\ \mathrm m\) 隧道内的洞口流动诊断通过，并满足第2.5节余量；
4. 域内有足够测点支撑候选模型；
5. 不因主体结果或锁箱残差回调。

检测限记为：

\[
\Delta T_{\mathrm{det}}
=
F_0^{-1}(1-\alpha),
\]

其中 \(F_0\) 是无火背景下数值温升波动的预注册分布，综合时间波动、随机种子差异以及网格和数值误差；\(\alpha\) 是先导阶段冻结的背景超阈概率。低功率工况在已冻结有效域内低于该阈值时转为删失点，不得据此缩小 \(\xi_h\) 或删除工况。

测点只分为三类：

| 角色 | 定义 | 用途 |
|---|---|---|
| `ACTIVE` | 域内且高于检测限 | 高斯似然、正向指标和反演 |
| `CENSORED_LOW_SIGNAL` | 域内但低于检测限 | 按冻结规则使用边际或条件左删失似然 |
| `QC_ONLY` | 域外或专用质量控制点 | 背景、洞口、异常检查，不调用正向公式 |

传感器名义数量只统计域内 `ACTIVE` 和 `CENSORED_LOW_SIGNAL`；QC 探头另计。正式软件对超域请求返回状态码，不外推，也不自动把温升设为零。

### 2.4 观测量边界与火焰状态

本研究的 \(T_g\) 是固定高度气体温度，不得与以下量混用：

- FDS `WALL TEMPERATURE`；
- 竖向温度分布最大值；
- 横截面平均烟层温度；
- 火焰温度；
- 单时刻湍流峰值。

火焰状态至少区分：

- `NON_IMPINGING`：非撞顶火焰；
- `TRANSITIONAL`：判定不确定或跨越状态边界；
- `IMPINGING`：火焰撞顶。

Heskestad 类关系仅用于设计筛查和反演时的可知代理：

\[
z_0=-1.02D_f+0.083Q_{\mathrm{kW}}^{2/5},
\]

\[
L_f=-1.02D_f+0.235Q_{\mathrm{kW}}^{2/5}.
\]

它们不是 FDS 火焰高度真值。开发阶段可以用反应率、温度场等场输出形成火焰状态标签；实际反演不得读取这些隐藏真值，必须使用冻结的、仅依赖已知输入和候选 \(Q,x_f\) 的保守分类器。当前协议没有预注册可供切换的完整火焰状态子域：若非撞顶与撞顶状态不能由同一闭合稳定描述，当前协议立即停止，现有数据整体降为探索性证据，不得看过结果后删点、自由缩小 Q-D 域或临时分层。只有新协议在任何新增主体结果产生前预注册完整、满秩的 Q-D 子域、对应位置设计、锁箱和既有数据继承规则后，才能分层或缩域重启；过渡不确定带返回 `FLAME_REGIME_AMBIGUOUS`，不强行并入任一层。

### 2.5 对称性与洞口余量

同一 \(|x-x_f|\) 公式只有在：

\[
\min(\lambda_-,\lambda_+)
\ge
\xi_h+b_{\mathrm{open}}
\]

且左右速度、峰移和温度曲线通过等效门时才可使用。\(b_{\mathrm{open}}\) 由现有 \(100\ \mathrm m\) 隧道的先导流场和不对称性诊断保守冻结，不另建加长隧道。该门只限制本固定长度内允许的 \(x_f\) 范围，不能证明长度可外推。

全局不对称度可写为：

\[
A_{\mathrm{global}}
=
\frac{
\sum_s w_s
|\Delta T_+(s)-\Delta T_-(s)|
}{
\sum_s w_s
\{\Delta T_+(s)+\Delta T_-(s)\}/2
+\varepsilon_T
},
\]

其中 \(w_s\ge0\)、\(\sum_s w_s=1\)，\(\varepsilon_T>0\) 具有温升单位并由背景数据冻结。对称性采用等效检验，不能用“差异不显著”直接认定对称。

### 2.6 虚拟原点只作附录敏感性

主文不建立第二套高度、坐标和几何变量。虚拟原点候选仅定义为：

\[
H_v=H-(z_f+z_0).
\]

敏感性模型 \(M_v\) 在公式内部将 \(H_g\) 一致替换为 \(H_v\)，但有效域、测点角色、洞口余量和实际测温坐标仍按本章几何合同判定。每个候选必须满足 \(H_v>0\) 及 Heskestad 关系的火焰状态和标定域；不得靠截断 \(H_v\) 强行消除奇点。

\(M_v\) 不进入当前方案的正向短名单、反演或 Fisher。若附录敏感性显示其稳定优势，应在 `A_active` 前停止当前流程并发布新版协议，完整定义其 \(Q\) 依赖、反演导数和适用域后再重启；不能在本方案内自动升级。主文不为这一可选候选预先铺设重复字段。

## 3. FDS 数据库与质量验证

### 3.1 数据块与可识别性

数据库数量指唯一物理条件，不包含网格、随机种子或时间块重复。全部主体和验证工况均使用 \(100\times10\times5\ \mathrm m\) 隧道。正式运行前先检查设计矩阵秩和变量混叠，不把“约 42 组”等数量配额当作充分性证明。

| 数据块 | 目的 | 最低要求 |
|---|---|---|
| 前置验证 | 冻结网格、背景、测高、洞口余量和输出合同 | 无火背景；低/高功率网格；多个候选测高；代表种子；固定域内洞口诊断 |
| \(Q-D_f\) 识别 | 重发现最大温升尺度和火源尺寸依赖 | 多个 \(Q\) 与多个 \(D_f\) 交叉；同一 \(D_f\) 有多个 \(Q\)，同一 \(Q\) 有多个 \(D_f\)；固定火源形状和朝向 |
| 偏移火源开发 | 检验平移、洞口余量和位置反演 | 中心及两侧成对位置；固定全局传感器坐标 |
| 开发集 | 公式/结构重发现及反演检验 | 覆盖 \(Q,D_f,x_f\) 标定域且按物理条件分组 |
| FDS 锁箱 | 一次性泛化评价 | 含未见完整 \(Q,D_f,x_f\) 组合、设计边界及中心/偏移火源 |

`HRRPUA` 由目标 \(Q\) 和离散燃烧面积派生，不是第三个独立设计因子。不得固定 `HRRPUA` 而使 \(D_f\propto\sqrt Q\)；实际离散面积和实际平均 HRR 必须进入设计审计。代表性 \(Q-D_f\) 单元均应包含中心和成对偏移位置，使 \(x_f\) 不与 \(Q,D_f\) 混叠；锁箱位置也必须位于预注册允许范围内，不作超域外推。

该数据库可以识别固定几何下的 \(Q\) 指数、\(D_f\) 依赖和形状结构，但**不能**声称重发现 \(H_g^{-5/3}\) 或 \(W/H_g\) 规律。固定 \(AR=2\) 时，转换位置只能建模为共享常数，或在证据支持时建模为 \(Q^*,d\) 的函数。

每个数据记录至少包含：

- `physical_case_id`：物理条件和分组主键；
- `parent_case_id`：同一 \(Q,D_f\) 下中心/偏移位置配对的上级分组键；
- `run_chid`：网格、种子和复现实跑实例；
- `replicate_id`、`subset`、`purpose`；
- FDS 版本、输入哈希、模型版本；
- 输入、工作目录和输出路径。

运行身份采用唯一四级链，且 `run_chid` 与 FDS 输入内的 `CHID` 相同：

- `run_chid` 唯一标识一条科学轨迹；完全相同核心输入的技术重试和只改变白名单 `T_END/RESTART` 的合法续算沿用该 `run_chid`；
- 每次 FDS 进程启动都必须生成新的 `job_attempt_id` 和独立、不可覆盖的 attempt 目录，初跑、重试与每个 RESTART 段均不得复用旧 attempt；
- RESTART 必须记录父 `job_attempt_id`、父检查点 SHA-256 和连续时间链；父哈希不符、链分叉或时间拼接不连续时整条接受链拒绝；
- 网格、随机种子、FDS 精确版本、传感器/输出配置、生成器核心逻辑或任一物理参数等非白名单变化，必须生成新的 `run_chid` 与 `run_core_sha256`；不得通过改名目录掩盖核心输入变化。

同一 `physical_case_id` 的空间点、时间块、随机种子和派生样本不得跨开发集与锁箱。检验平移泛化时，同一 `parent_case_id` 下的中心/偏移配对默认处于同一折；若专门采用留位置外推，必须在主体前注册该外层分法。

开发/锁箱清单、分组键和输入哈希应在主体结果产生前固定。锁箱输入可以预先生成，但在第5章规定的冻结完成前不得运行后处理或查看目标温度结果。

### 3.1.1 外部计算合批与科学闸门分离

外部服务器的计算批次与本方案的科学证据闸门是两个不同概念。为减少数据往返和排队次数，在共同前置条件已经通过、且后续输入均已预注册、静态审计、登记唯一 `job_attempt_id` 并冻结 SHA-256 后，允许把多个后续计算阶段合并为一个外算批次。该规则只改变调度，不改变数据边界、门限、作业预算或停止条件。

G2 的三个背景工况通过后，剩余 13 条已冻结先导输入可以一次性外算。回传后仍必须按“中网格 heavy → 网格/种子 → 洞口/平移”的顺序形成科学结论。允许对全部回传结果先做输入哈希、FDS 版本、正常结束和文件完整性的技术接收；后置阶段的温度、网格、种子、对称性和火焰状态等科学指标，在前置阶段通过前不得生成、查看或用于决策。

若前置闸门失败，已经算出的后置结果必须隔离并标记为 `QUARANTINED_BY_UPSTREAM_GATE`，不得用于放宽阈值、裁剪工况或形成当前协议结论；只有新协议逐项明确继承时才可重新使用。锁箱仍严格服从 `A_active`/B（以及按需冻结 C）后的单次开箱规则，不适用本条合批授权。

### 3.4 网格、洞口和随机性

网格比较不能只依赖单一羽流分辨率指标，至少比较：

\[
\Delta T_p,\quad
x_p,\quad
A_{\mathrm{global}},\quad
\overline{\Delta T}(\xi\le\xi_h),\quad
\xi_1,\quad
Q_{\mathrm{actual}}.
\]

无风对称性研究要求内部 MESH 接口尽可能镜像，并静态检查：

- 完整覆盖、无重叠、无缝隙；
- 左右分区镜像；
- 燃烧器不被内部 \(x/y\) 边界切穿；
- 镜像分区与原分区对目标量的影响。

洞口诊断必须覆盖最大允许偏移火源，并在现有 \(100\ \mathrm m\) 隧道内检查域内峰值、曲线、速度和不对称度。若无法给出保守洞口余量，则缩小 \(x_f\) 和 \(\xi_h\) 的允许范围，不另建加长隧道来扩大适用域。

时间块 Bootstrap 不能代替 LES 随机种子。低、中、高功率及设计边界的代表条件至少运行 3 个独立种子，资源允许时采用 5 个。

网格版本规则是硬停线而不是同版回退。原 v1.0 的 0.25 m 严格网格门失败后已经停止，且未在 v1.0 内直接把 0.20 m 升格为工作网格；当前 v1.1 是用户明确批准的版本化修订，继续采用 0.25 m、保留 13% 峰值网格不确定性并禁止声称严格网格独立。若新证据否定当前修订，或后续希望改用 0.20 m，v1.1 必须停止并发布 v1.2 或更高版本；新版本须重新验证 0.20 m 相对更细网格的同一门限，并重新冻结燃烧器离散、测高、有效域、位置映射、资源预算、开发集与锁箱。当前协议不得混合 0.25 m 与 0.20 m 正式结果拟合。

## 4. 正向显式公式重发现

### 4.1 总体形式

候选公式统一写为：

\[
\boxed{
\widehat T_g(x,z_s)
=
T_0+
T_0
F_T(Q^*,d,s_f)
\Theta(\xi;Q^*,d,s_f)
}
\]

其中：

\[
F_T=\frac{\Delta T_p}{T_0},
\qquad
\Theta(0)=1.
\]

公式只在第2章支持域内调用。\(s_f\) 是冻结的火焰状态或适用层级；若主体只保留一个状态，则不把它作为拟合输入。固定 \(H_g=5\ \mathrm m\) 与 \(AR=2\) 的影响吸收到系数和适用边界中，不能把它们伪装成已识别的自变量。\(F_T=\Delta T_p/T_0\) 还要求峰值位置等效门证明 \(x_p\) 与 \(x_f\) 一致；若不满足，不得通过事后平移曲线维持该对称公式。

### 4.2 最大温升闭合

固定几何下，最大温升从最简单的功率闭合开始。\(Q_{\mathrm{ref}}\) 和 \(D_{\mathrm{ref}}\) 是先导阶段冻结的域内参考值，只用于降低参数相关性，不参与模型选择：

\[
\frac{\Delta T_p}{T_0}
=
C_m
\left(\frac{Q}{Q_{\mathrm{ref}}}\right)^a.
\]

若交叉设计证明 \(Q\) 与 \(D_f\) 可分离，再比较火源尺寸闭合：

\[
\boxed{
\frac{\Delta T_p}{T_0}
=
C_m
\left(\frac{Q}{Q_{\mathrm{ref}}}\right)^a
\left(\frac{D_f}{D_{\mathrm{ref}}}\right)^{b_d}
}
\]

在固定 \(H_g\) 下，它等价于把常数吸收后的

\[
F_T=C_T(Q^*)^a d^{b_d}.
\]

\(a,b_d\) 先由数据盲估，再把 \(a\) 与经典 \(2/3\) 量级比较，不预先锁死。若 \(D_f\) 项没有稳定的分组外层增益，则采用只含 \(Q\) 的公式；“没有额外尺寸效应”也是允许的结构识别结果。

Li、Lei 与 Ingason 的低风关系只作带单位基准：

\[
\Delta T_{\max,\mathrm{Li}}
=
17.5
\frac{Q_{\mathrm{kW}}^{2/3}}
{H_{g,\mathrm m}^{5/3}}.
\]

这里必须使用 kW 和 m。该关系在本研究中只按固定 \(H_g=5\ \mathrm m\) 计算文献量级；其最大顶棚气温定义也不天然等于本研究固定测高的纵向峰值。因此，本项目既不拟合也不声称重发现 \(5/3\) 高度指数，系数 17.5 也不是验收门。只有重复残差和完整物理工况分组验证同时支持时，才进一步比较火焰状态分层；固定 \(AR\) 不进入闭合。

### 4.3 纵向形状候选

**形状 S1：平滑单区幂律**

\[
\Theta_s(\xi)
=
\left[1+(A_s\xi)^2\right]^{-p_s/2},
\qquad
A_s,p_s>0.
\]

它满足：

\[
\Theta_s(0)=1,\qquad
\Theta_s'(0)=0,\qquad
\Theta_s'(\xi)\le0.
\]

**形状 S2：拉伸指数统计对照**

\[
\Theta_e(\xi)
=
\exp(-A_e\xi^n),
\qquad
A_e>0.
\]

作为正向对照时要求 \(n>1\)。若成为需要局部 Hessian 或解析 Fisher 的主模型，则要求 \(n\ge2\)；\(1<n<2\) 时区间只使用剖面似然和 Bootstrap。

**形状 S3：连续两区结构**

\[
\Theta_1(\xi)
=
\left[1+(A\xi)^2\right]^{-p_1/2},
\qquad
0\le\xi<\xi_1,
\]

\[
\Theta_2(\xi)
=
\Theta_1(\xi_1)
\left[1+B(\xi-\xi_1)\right]^{-p_2},
\qquad
\xi_1\le\xi\le\xi_h.
\]

至少强制 \(C^1\) 连续：

\[
B=
\frac{p_1A^2\xi_1}
{p_2(1+A^2\xi_1^2)}.
\]

独立参数为 \(\{A,p_1,p_2,\xi_1\}\)，不再单独拟合 \(B\)。

参数必须满足：

\[
A,p_1,p_2>0,
\qquad
0<\xi_1<\xi_h.
\]

Alpert 平顶棚关系只作近区量级对照；Oka 与 Oka 2016 支持特定自然通风隧道的分区结构，但其观测量和边界与本项目不同。\(p_2=1/2\) 只在模型冻结后作事后一致性比较，不进入先验、搜索中心或通过门。

### 4.4 转换位置与跨工况闭合

固定 \(AR=2\) 时，侧墙量级

\[
\frac{AR}{2}=1
\]

只能作为转换位置的几何参照，不能用于识别宽高比指数。仅在 S3 通过结构门后，按复杂度比较：

\[
\xi_1=C_\xi,
\qquad
\xi_1=C_\xi d^s(Q^*)^t.
\]

跨工况闭合遵循：

- 能共享的参数先共享；
- 只有重复残差和分组验证支持时，才让形状参数随 \(Q^*,d\) 作低阶变化；
- 简单模型与复杂模型性能等价时采用简单模型；
- 两区式还必须满足参数可识别、每段测点充分和场诊断相符。

最终拟合优先在所有开发工况的原始温升上联合完成。逐工况参数只用于初值、诊断和不确定性检查，不意味着每个参数都需要一条复杂经验式。

### 4.5 正向报告指标

至少报告：

- \(\Delta T_p\) 相对误差；
- 有效域 NRMSE/MAE；
- 峰值位置误差；
- 对称等效指标；
- 工况平均与最不利误差；
- 预测区间覆盖率；
- 参数区间、边界命中和结构稳定性。

## 5. 统计拟合与模型选择

本章是分组、似然和冻结顺序的唯一权威定义位置。

### 5.1 处理流程与不确定性

每个运行依次完成：

1. 审查版本、日志、VENT、HRR 和文件完整性；
2. 检查无机械风边界、背景偏流和准稳态窗口；
3. 同步时间平均全部测点；
4. 提取峰值、对称性和火焰状态；
5. 按第2章确定测点角色；
6. 拟合正向候选；
7. 扰动时间窗、网格和随机种子；
8. 保存协方差、剖面似然、残差及采用/否决原因。

时间块 Bootstrap 必须对所有空间测点同步抽取相同时间块，块长由有效域内最慢信号的相关时间尺度确定。它只描述单次 LES 时间波动，不能替代随机种子、网格、洞口和模型偏差。

不确定性按 `physical_case_id → random_seed → 同步时间块` 分层汇总。正向参数、候选结构和模型误差的不确定性必须传播到第6章反演，不能只把传感器噪声带入反演区间。

### 5.2 ACTIVE 与删失的统一似然

全部统计似然使用温升，不混用绝对温度阈值。对工况 \(j\)，令 \(\mathbf r_{A,j}=\mathbf y_{A,j}-\boldsymbol\mu_{A,j}\)，ACTIVE 点采用保留空间相关性的高斯项：

\[
L_{A,j}
=
\frac12
\mathbf r_{A,j}^{T}
\Sigma_{AA,j}^{-1}
\mathbf r_{A,j}
+
\frac12\log\det\Sigma_{AA,j}.
\]

执行顺序由简到严。先导或每个训练折若证明删失点之间以及删失点与 ACTIVE 点之间的条件相关对候选排序和覆盖率影响可忽略，域内低信号点可使用边际左删失项：

\[
L_{C,j}
=
-\sum_{k\in C_j}
\log\Phi\!\left(
\frac{\Delta T_{\mathrm{det}}-\mu_{k,j}}
{\sigma_{k,j}}
\right).
\]

若该简化条件不成立，则升级为严格的条件多元删失项：

\[
L_{C,j}
=
-\log
\Pr\left(
\mathbf Y_{C,j}
\le
\Delta T_{\mathrm{det}}\mathbf 1_C
\mid
\mathbf Y_{A,j}=\mathbf y_{A,j}
\right).
\]

完整分块协方差和多元 CDF 实现放入统计附录，不在主线展开。采用边际版还是条件版的诊断规则必须在锁箱前冻结，并只使用开发数据。正向总目标统一记为：

\[
\boxed{
L_{\mathrm{fwd}}
=
\sum_j
\left(
L_{A,j}
+
L_{C,j}
\right)
}
\]

\(\Sigma_{AA,j}\) 至少考虑时间波动、空间相关性和模型误差地板。观测误差与模型误差若非独立，必须处理交叉协方差，不能重复计入。域外 QC 点不进入似然。

## 6. 直接反演 \(Q,x_f\)

### 6.1 反演接口

冻结正向公式对第 \(i\) 个传感器给出：

\[
\widehat T_i(Q,x_f)
=
T_0
+
T_0
F_T[Q^*(Q),d,\widehat s_f(Q,x_f)]
\Theta[
\xi_i(x_f);
Q^*(Q),d,\widehat s_f(Q,x_f)
].
\]

已知量为：

\[
D_f,\ H,\ W,\ z_f,\ T_0,\ \{x_i,z_s\},
\quad
\text{材料与燃料类别}.
\]

待估参数采用无量纲形式：

\[
\eta_1=\log(Q/Q_{\mathrm{ref}}),
\qquad
\eta_2=(x_f-x_{\mathrm{ref}})/H_g.
\]

反演严格条件于已知 \(D_f\) 以及固定 \(L=100\ \mathrm m,W=10\ \mathrm m,H_g=5\ \mathrm m\)。候选 \(Q\) 更新 \(Q^*\) 和火焰状态；候选 \(x_f\) 更新 \(\xi_i\)、洞口余量并可能改变状态分类。\(d,H_g\) 和测温坐标不随候选移动。状态切换边界按硬域处理；梯度优化和 Fisher 只在远离过渡带的固定状态分支内使用，不跨分类边界假装目标光滑。开发集另报告 \(D_f\) 合理误设对 \(\widehat Q,\widehat x_f\) 的敏感性，但不把 \(D_f\) 升级为第三个待估参数。

### 6.2 固定观测集合

不得让候选 \(x_f\) 通过改变 active set 躲避残差。端到端流程为：

1. 用原始观测的最高温簇得到粗定位区间；
2. 按冻结物理窗口和布局规则选出固定观测集合；
3. 正式优化期间不随候选增删点；
4. 任一进入似然的点对候选 \(x_f\) 超出第2章支持域时，该候选返回域错误；
5. QC 点不调用正向公式。

粗定位、选点、优化和区间计算必须作为一条流水线在开发集和锁箱中评价。Bootstrap 时也应重跑整条流水线，不能用真实 \(x_f\) 预先固定有利观测点。

### 6.3 反演损失

反演沿用第5章同一温升似然。令：

\[
\boldsymbol\mu(Q,x_f)
=
\widehat{\mathbf T}(Q,x_f)
-
T_0\mathbf 1,
\]

\[
\Sigma_{\mathrm{tot}}
=
\Sigma_{\mathrm{obs}}
+
\Sigma_{\mathrm{forward}}.
\]

若两类误差不独立，应加入交叉协方差。

总目标为：

\[
\boxed{
L_{\mathrm{inv}}
=
L_A
+
L_C
+
P_{\mathrm{domain}}
}
\]

其中 \(L_A,L_C\) 按第5.2节冻结的同一删失规则计算。\(P_{\mathrm{domain}}\) 优先实现为硬支持约束，限制：

- \(Q,Q^*,d\) 位于标定域，且几何与固定研究场景一致；
- \(x_f\) 位于允许火源区；
- 固定观测集合对该候选位于支持域；
- 火焰状态不越过冻结层级；
- 两端洞口余量满足第2.5节。

只有无删失、协方差固定且域约束可化为简单参数边界时，目标才退化为非线性最小二乘。包含条件 CDF、参数相关 `logdet` 或一般硬约束时，必须使用相应负对数似然优化器。

### 6.4 求解与可辨识性

求解流程：

1. 在 \(Q-x_f\) 平面做有界粗网格搜索；
2. 保留多个低损失初值；
3. 用 L-BFGS-B、`trust-constr` 或经验证的同类优化器精细求解；
4. 用一种不依赖梯度的算法复核代表工况；
5. 检查二维目标面、多初值和边界命中；
6. 用剖面似然或物理工况 Bootstrap 给出区间。

至少报告：

\[
\frac{|\widehat Q-Q|}{Q},
\qquad
\frac{|\widehat x_f-x_f|}{H_g},
\]

以及覆盖率、区间宽度、多解率、失败率、最不利工况和拒绝率。局部 Hessian 只用于解附近二阶可微且非奇异的模型。

正向通过而反演不可辨识是允许结论：保留正向成果，明确报告信息不足，不得强行给出单值火源估计。

### 6.5 拒绝状态

软件至少区分：

- `OUT_OF_CALIBRATION_DOMAIN`；
- `OPENING_MARGIN_FAIL`；
- `FLAME_REGIME_FAIL` / `FLAME_REGIME_AMBIGUOUS`；
- `NO_QUASI_STEADY_WINDOW`；
- `ASYMMETRY_FAIL`；
- `CENSORED_DOMINANT`；
- `NON_IDENTIFIABLE`；
- `SENSOR_INCONSISTENT`。

这些状态只说明适用域或信息条件不满足。没有专门异常数据库时，不得进一步声称已经识别多火源、阻塞、故障或排烟类型。

## 8. 可选增强、论文成果与边界

### 8.1 Fisher 传感器布局

Fisher 分析只在冻结 B、直接反演基线已建立且锁箱未打开时考虑，用于解释局部可辨识性和提出候选布局。对 \(\boldsymbol\eta=[\log(Q/Q_{\mathrm{ref}}),(x_f-x_{\mathrm{ref}})/H_g]^T\)，采用：

\[
I
=
J^T
\Sigma_{\mathrm{tot}}^{-1}
J,
\qquad
J_{ik}=\frac{\partial\mu_i}{\partial\eta_k}.
\]

分析使用固定全局坐标，传播正向参数不确定性，对删失数据采用期望或 Monte Carlo 信息；协方差随参数变化时改用期望负 Hessian 或 Monte Carlo。信息矩阵奇异即返回 `NON_IDENTIFIABLE`。候选布局必须在冻结 C 后用端到端反演证明优于等间距基线，否则 Fisher 只作附录或取消。

### 8.2 可微物理解码

本节是**导师触发的备用附加实验合同，当前不实施**。默认记录为 `G7_SKIPPED_NOT_REQUESTED`，不训练网络、不建立冻结 C，也不阻塞主体锁箱。只有 `A_active`/B 均通过、锁箱未打开且导师明确要求时，才以带日期的协议补充激活；锁箱打开后再激活时必须另建未见网络锁箱。

方法参考《理论研究实施方案》的集合编码—物理解码路线，但只复用方法骨架。历史有风模型中的 \(U\)、上下游闭合参数、旧权重和性能结果均不进入本研究；网络必须重新连接冻结 B 的无风正向公式。它位于显式公式和直接反演之后，是拓展内容，不是论文成立条件。

**1. 位置感知集合输入**

第 \(i\) 个可用传感器输入定义为：

\[
\mathbf s_i=
\left[
\frac{\widetilde{\Delta T}_i}{s_T},
\frac{x_i-L/2}{H_g},
m_i,
c_i,
\frac{\sigma_i}{s_T}
\right],
\]

其中 \(m_i\in\{0,1\}\) 是缺测掩码，\(c_i\in\{0,1\}\) 是低信号删失标记，\(s_T\) 是只用开发集冻结的温度尺度，\(\sigma_i\) 来自冻结 B 的误差模型。ACTIVE 点输入实测温升；删失点的温度通道只输入 \(\Delta T_{\mathrm{det}}\) 和 \(c_i=1\)，不得读取 FDS 中真实的亚阈值温升；`QC_ONLY` 不作为温度输入。全局网络输入只保留 \(d=D_f/H_g\) 和标准化 \(T_0\)；固定几何协议标识只作域门，不作为可学习特征。网络不得读取任何反应率、火焰高度真值或真实 \(x_f\) 派生量。

所有传感器共享轻量 MLP 编码器：

\[
\mathbf h_i=\varphi(\mathbf s_i),
\qquad
\mathbf h=
\left[
\operatorname{mean}_{m_i=1}\mathbf h_i,
\operatorname{max}_{m_i=1}\mathbf h_i,
\frac{N_{\mathrm{valid}}}{N_{\max}},
\frac{N_{\mathrm{cens}}}{N_{\mathrm{valid}}}
\right].
\]

全局量不在每个传感器上重复拼接；输出头 \(\psi(\mathbf h,d,\widetilde T_0)\) 产生 \(z_Q,z_x\)。该集合结构对传感器顺序不敏感，并允许不同数量、随机缺测和不规则布局；网络宽度、层数和正则化只用开发集分组交叉验证选择。

**2. 输出约束与可微解码**

输出被限制在冻结标定域：

\[
\log\widehat Q
=
\log Q_{\min}
+
\left(\log Q_{\max}-\log Q_{\min}\right)\sigma(z_Q),
\]

\[
\widehat x_f
=
x_{\min}
+
(x_{\max}-x_{\min})\sigma(z_x).
\]

网络预测随后送入冻结 B 的统一 forward callable：

\[
\widehat{\Delta T}^{\mathrm{physics}}_i
=
F_B(\widehat Q,\widehat x_f;D_f,x_i)
=
T_0
F_T[Q^*(\widehat Q),d,\widehat s_f]
\Theta\!\left(
\frac{|x_i-\widehat x_f|}{H_g};
Q^*(\widehat Q),d,\widehat s_f
\right),
\]

\[
\widehat s_f
=
\mathcal C_f(\widehat Q,\widehat x_f),
\qquad
\mathbf T^{\mathrm{obs}}
\rightarrow
(\widehat Q,\widehat x_f)
\rightarrow
\widehat{\mathbf T}^{\mathrm{physics}}.
\]

解码器必须复用第2、5、6章的有效域、火焰状态、删失和拒绝合同；不得另写一套近似公式。状态过渡带或公式不可微分支只允许返回冻结的拒绝状态，不能为网络训练强行平滑后冒充正式物理模型。

**3. 联合损失**

\[
\mathcal L
=
\lambda_s\mathcal L_{\mathrm{source}}
+
\lambda_T\mathcal L_{\mathrm{recon}}
+
\lambda_c\mathcal L_{\mathrm{cens}}
+
\lambda_r\mathcal R,
\]

\[
\mathcal L_{\mathrm{source}}
=
w_Q(\log\widehat Q-\log Q)^2
+
w_x\left(\frac{\widehat x_f-x_f}{H_g}\right)^2,
\]

其中 \(\mathcal L_{\mathrm{recon}}\) 采用第5.2节冻结的 ACTIVE 点项 \(L_A\)，\(\mathcal L_{\mathrm{cens}}\) 采用删失项 \(L_C\)，使网络预测的火源参数必须重新生成观测温度并正确处理删失点；\(\mathcal R\) 只包含开发阶段冻结的轻量权重衰减。损失权重在训练折内确定，不能用锁箱调节。

**4. 训练、对照与成立门**

1. 用冻结结构的正向公式在标定域内生成含相关噪声、位置误差、偏置、随机/连续区段缺测和模型残差的合成观测作预训练；合成数据只用于优化初始化和软件测试，不是物理证据。
2. 用 FDS 开发工况微调，并按 `physical_case_id`、`parent_case_id` 完整分组。网络交叉验证必须调用对应训练折重拟合的正向系数和误差模型，不能让全开发集 B 系数向验证折泄漏；超参数冻结后，才用全开发集 B 公式训练最终 C。
3. 比较四种方法：显式公式直接优化、固定布局全连接网络、纯数据集合网络、参数监督加物理解码集合网络。
4. 将输入合同与归一化、网络结构、损失权重、扰动分布、早停规则、集成/Bootstrap 区间、评价指标和拒绝阈值一并冻结为 C 后，才与主体模型一次性打开第7章锁箱。

评价固定包含：`R0` 完整观测、`R1` 一倍冻结相关噪声、`R2` 随机缺测 30%、`R3` 连续失效约 20% 测点区段、`R4` 一倍相关噪声与 30% 随机缺测叠加。扰动版本始终附着于原 `physical_case_id`，不能当作新增独立样本。

采用五个固定初始化的轻量集成模型，在开发集折外预测上校准区间、重建残差和模型分歧阈值。若有效点不足、删失占主导、重建残差超阈、输出持续命中边界或模型分歧过大，继承第6.5节拒绝状态，并可返回 `NETWORK_DISAGREEMENT`；不得进一步声称识别了具体异常类型。

网络进入正文的最低条件不是“任一指标变好”，而是同时满足：

1. `R0` 相对直接优化精度非劣：Q 相对误差中位数最多增加 2.5 个百分点，位置误差中位数最多增加 \(0.10H_g\)，联合误差中位数差不超过 0.10，并独立通过主体绝对精度与覆盖门；
2. 同一冻结 CPU 环境的单样本端到端中位延迟至少快 20 倍，配对 Bootstrap 95% 速度比下界至少为 10 倍，网络 p95 延迟不超过 100 ms；计时包含五成员、共同预处理、物理解码和拒绝检查，不含磁盘、通信和区间 Bootstrap；
3. 若要进一步主张缺测/噪声优势，R4 的联合误差中位数须至少降低 15%、至少 7/10 锁箱工况更优且拒绝数不增加，并在 R1–R3 中至少再有一种满足同一标准。

只通过前两项时，网络仅作为“快速反演近似”；第三项也通过时，才形成鲁棒性附加方法贡献。精度或速度任一失败时，只保留负结果、初值器或附录软件结果。G7 未激活则记为 `NOT_APPLICABLE`，不能解释成网络无优势。

### 8.3 论文成果与两层创新

论文结果部分必须设置独立的“符号回归公式发现过程”章节，并置于最终公式与反演结果之前。该章无论最终由 `A_SR` 还是 `A0` 成为 `A_active` 都必须保留，至少包含：

1. 峰值任务和形状任务各自的误差—复杂度 Pareto 前沿，并标出经统一常数复估后的候选；
2. 规范化候选结构族、代数/参考尺度/预测等价关系、复杂度和自由常数数目；
3. 核心变量在 9 个外层折与 20 个全开发集正式种子中的选择频率，搜索失败、超时和无可行式均计入分母；
4. 候选结构的跨折稳定性、逐父组误差、最不利父组表现和 7/9 稳定门结果；
5. 量纲、连续域有限性、正值、峰值归一、单调性和功率趋势等物理约束的逐类淘汰数量、原因及最小裕量；
6. 选定结构回到原始温升后的最终联合重拟合、参数区间、误差模型、相对 A0 的决策依据和 `A_active` 来源。

该章不得只展示最后一条公式，也不得只统计成功搜索；完整过程表和机器可读证据应与正文图表一一对应。

最低成果按科学主次排列：

1. 固定 \(100\times10\times5\ \mathrm m\) 几何内，最大温升的 \(Q\) 尺度及必要 \(D_f\) 依赖公式；
2. 有效高温域纵向衰减的单区/拉伸指数/连续两区结构辨识及跨工况闭合；
3. 条件于已知 \(D_f\) 和固定几何的 \(Q,x_f\) 直接反演器、区间与拒绝边界；
4. 可追溯且版本分层的数据库（冻结的 FDS 6.9.1 开发集与 FDS 6.10.1 独立锁箱）、分组验证和一次性锁箱结论。

仅当导师在锁箱打开前激活 G7 时，才建立冻结 C 并评价第8.2节。通过后可增加“位置感知集合编码器 + 冻结公式可微解码器”、四模型对照和鲁棒性矩阵作为拓展成果；已激活但未通过时只保留软件、负结果或附录对照。未激活时不要求任何网络交付物，也不能写成网络失败。

**第一层火灾科学贡献**是物理约束下的公式/结构重发现：盲估功率尺度和火源尺寸项，不预设必须为单区或两区，并由跨工况闭合、嵌套分组验证和独立 FDS 锁箱确定最终表达。即使 \(a\approx2/3\) 或单区模型胜出，只要候选竞争和证据链成立，也分别说明经典量级得到支持，或没有证据增加两区复杂度。

**第二层方法贡献**是正向先筛选、反演再检验，并用物理工况分组、`A_active`/B 冻结、删失/QC 合同、锁箱和拒绝输出控制证据泄漏。反演不能参与 `A_active` 的选择。

本研究不要求首次提出完全新的函数形式，但仅重新拟合一条已有幂律不足以支撑“重发现”。数值证据来自盲估尺度、未预设区段数的结构竞争、跨工况闭合、不确定性和独立 FDS 锁箱；FDS、归一化曲线或神经网络本身不构成创新。

### 8.4 主要风险与降级

| 风险 | 处置 | 允许的降级结论 |
|---|---|---|
| 固定几何无法识别高度或宽高比迁移 | 在题目、公式和结论中锁定适用几何 | 不作跨 \(H\)、跨 \(AR\) 外推 |
| 两区参数不稳定 | 退回平滑单区 | 不主张两区机制 |
| 符号回归没有稳定替代式 | 封存 `SR_NO_REPLACEMENT`，生成 `A_active(source=A0)` | 报告未发现足以替代人工候选基准的新结构 |
| SR 引擎冲突或 AI Feynman 2.0 不可复现（仅批准 G5-SR 后） | 仍按冻结父组门裁决；取消附加审计而不临时换引擎 | 不把算法一致性当成必要证据 |
| 偏移火源系统不对称 | 缩小允许位置域或否定对称式 | 只保留中心/深埋火源 |
| 当前 0.25 m 网格修订被新证据否定，或计划改用 0.20 m | 当前协议停止；发布下一版协议并重新完成细网格比较、离散映射、预算与全套冻结 | 不得在同版切换网格或混合拟合；当前版本不新增主体结论 |
| 洞口或种子差异过大 | 仅按预注册位置域和重复规则处理；若需超出冻结选项则发布新协议 | 缩小已预注册位置域，或降低相应主张 |
| 火焰状态混杂且无预注册完整子域 | 当前协议停止；新协议预注册完整、满秩 Q-D 子域、位置设计与新锁箱 | 现有数据库只作探索性证据，不允许事后删点成层 |
| 正向通过但反演多解 | 增加已知条件或改变布局 | 正向成立，反演不成立 |
| 独立锁箱泛化失败 | 不回调原锁箱；修订后发布新协议并建立新未见集 | 降为开发集探索性数值关系 |
| Fisher 无稳定布局增益 | 取消或移入附录 | 不影响主体闭环 |
| 物理解码网络无稳定增益（仅在已激活 G7 时） | 保留为拓展软件、初值器或附录对照 | 不列为主体创新，不影响直接反演 |
