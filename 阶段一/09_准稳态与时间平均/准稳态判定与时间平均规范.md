# §1.9 准稳态识别与时间平均方法 · 执行协议与报告模板

> §14。不得仅凭预设时段认定准稳态；综合判断后取 10~30 s 稳定窗口时间平均；
> 不确定性用分块 Bootstrap，分块长度按自相关特征确定。
> 计算由 `src/quasi_steady_detect.py` 与 `src/time_average_bootstrap.py` 完成。

## 1. 准稳态判据（综合，非单一）

默认先对温度与速度作 15 s 尾随平均，再在 90 s 长趋势窗口内检查：

1. 总 HRR 相对波动 ≤ 阈值（默认 15%，不预先平滑）；HRR 时间均值是否
   接近输入目标仍由 `check_fds_results.py` 单独检查，不能用本阈值替代；
2. 平滑后的最大顶棚温度趋势 ≤ 阈值（默认 0.15 °C/s）；
3. 平滑后的代表测点温度趋势 ≤ 阈值（默认 0.15 °C/s）；
4. 由平滑速度剖面求得的上游回流长度趋势 ≤ 阈值（默认 0.05 m/s）；
5. `cross_section_integrals.csv` 中完整 `J_T(x)` 剖面在趋势窗口内的相对漂移
   `||dJ_T/dt|| Δt / ||mean(J_T)||` ≤ 5%。缺少时输出
   `UNCHECKED_NO_FIELD_DATA`，不得视为已检查。

每个判定点已经总结一个完整的 90 s 趋势窗口，因此不再要求随后的每个约
1 s 滚动点连续 30 s 全部通过。首个合格趋势窗的末 30 s 用于时间平均。
FDS 自适应时间步造成的轻微不等间隔允许存在；只拒绝大于中位采样间隔
1.25 倍的长空档。

这里的放宽是为了容纳 LES 的正常脉动，不等于取消稳定性检查。90 s 长趋势、
回流长度和 `J_T(x)` 漂移仍须同时通过；缺测、持续漂移和不完整场数据仍会失败。

满足后，从该时刻起取 **10~30 s** 稳定窗口计算时间平均 `T_i_bar`。
主体公式与反演用**时间平均温度**，不用瞬时湍流波动。

## 2. 时间平均与分块 Bootstrap

- 分块长度 `L_b`：由温度时序**自相关函数首过零点**估计（`time_average_bootstrap._autocorr_block_len`）；
- 以 `L_b` 非重叠分块作 Bootstrap 重采样（默认 2000 次）；
- 输出 `T_i_bar`（温升，相对 T_0）与 95% 置信区间；
- **不得**把连续时间点视为完全独立样本。

## 3. ΔT_noise 的确定

- 由分块 Bootstrap 的 sd（中位）作为 ΔT_noise 参考下限；
- 并结合 §3.6 随机种子重复工况的波动量化 ΔT_noise（最终用于强风删失阈值与不确定性）。

## 4. 执行

```
# 4.1 准稳态检测（逐工况）
python3 src/quasi_steady_detect.py --rundir outputs/runs \
  --chids gsA_m gsB_m gsC_m ... --outdir outputs/analysis/steady
#   → steady_windows.csv（各工况 t0、平均窗口）

# 4.2 时间平均 + 分块 Bootstrap（用上一步窗口）
python3 src/time_average_bootstrap.py --rundir outputs/runs \
  --steady-windows outputs/analysis/steady/steady_windows.csv \
  --outdir outputs/analysis/time_average
#   → 各 <chid>_Tbar_bootstrap.csv + time_average_database.csv
```

## 5. 不确定性来源（§20 一并记录）

- 时间窗口分块 Bootstrap；
- 测点 Bootstrap；
- 峰值位置扰动；
- 温度噪声扰动；
- 拟合区间变化；
- 不同随机种子对照。
