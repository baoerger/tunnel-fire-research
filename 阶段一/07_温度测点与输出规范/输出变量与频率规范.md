# §1.7 温度测点与 FDS 6.10.1 输出规范

## 1. 顶棚中心线测点

- 测点必须位于工况的均匀测量区：洞口缓冲至少 3H，并同时限制在 `[0.15L,0.85L]`。
- 火源 ±4H 内默认间距 0.5H，远场默认 H；端点和火源位置强制保留。
- 温度测点为气相 `z=0.90H`；纵向速度测点为气相 `z=0.95H`。
- 基准 L×W×H=100×10×5 m 时，测量区 `[15,85] m`，温度 z=4.5 m，速度 z=4.75 m。
- `generate_sensor_layout.py` 与 `generate_fds_case.py` 均调用 `tunnel_config.sensor_layout/sensor_heights`；外部工况传入 L/W/H 后不得复用基准高度。

## 2. 输出变量合同

| 类别 | FDS 记录 | 用途 |
|---|---|---|
| 顶棚气体温度 | `DEVC QUANTITY='TEMPERATURE'`，气相点无 IOR | 主体温度变量 |
| 纵向速度分量 | `DEVC QUANTITY='U-VELOCITY'`，气相点无 IOR | 回流长度与输运方向 |
| 区域总 HRR | `DEVC QUANTITY='HRRPUV'` + `SPATIAL_STATISTIC='VOLUME INTEGRAL'` | 火源是否有效及功率闭合 |
| 火源辐射/对流 | `_hrr.csv` 的 `HRR`、`Q_RADI` | `χ_r=-Q_RADI/HRR`，`Q_c,source=HRR+Q_RADI` |
| 顶棚净热通量 | `DEVC QUANTITY='NET HEAT FLUX', IOR=-3` | 壁面吸热参考 |
| 纵剖面 | `SLCF PBY=W/2` 的温度、密度、矢量速度 | 流向和回流可视化 |
| 横截面 | 多个 `SLCF PBX` | 横截面超温焓和纵向焓流 |
| 边界场 | `BNDF QUANTITY='WALL TEMPERATURE'` | 壁面温度参考 |

禁止使用 `U VELOCITY`、气相速度 `IOR=1`、`CONVECTIVE HRR` 设备、`STATISTICS='VOLUME INTEGRATION'` 或顶棚 `IOR=3`。`_hrr.csv Q_CONV` 是计算域能量收支项，不等同于火源经验对流 HRR。

## 3. 输出频率

```fds
&DUMP DT_DEVC=1.0, DT_HRR=1.0, DT_SLCF=5.0, DT_BNDF=10.0 /
```

- DEVC 和 HRR：1 s，供准稳态识别、时间平均和能量比例分析。
- SLCF：5 s；BNDF：10 s，以控制数据量。
- FDS 6.10.1 当前实跑 `_devc.csv` 为 C、m/s、kW、kW/m²，`_hrr.csv` 功率为 kW；分析不得硬编码该假设，必须读取单位行并经 `fds_io.normalize_units` 归一化。
- CSV 通常是单位行在前、字段名行在后；解析器同时兼容历史相反顺序。

## 4. 使用纪律

- 温度定义一旦确定，FDS、解析模型、反演和网络必须统一采用顶棚下方 0.10H 气体温度，不与壁温或热电偶响应温度混用。
- 偏移火源研究若要求固定传感器网格，应显式传入固定 `region/layout`；默认生成器会保证火源点存在。
- 正式分析前检查设备均在域内、ID 唯一、入口方向为 +x、`HRR_tot>0`，且日志无 BURNER VENT rejected。
