# §1.8 总/对流 HRR 定义与对流比例检查 · 执行协议与报告模板

> §9。反演目标统一为总 HRR `Q`；正向温度模型用对流 HRR `Q_c=(1−χ_r)Q`。
> 无量纲对流功率 `Q_c* = Q_c/[ρ_0 c_p T_0 √g H^(5/2)]`。
> 用 FDS 实际输出检验预设对流比例是否稳定。计算由 `src/check_convection_ratio.py` 完成。

## 1. 定义与口径

- **总 HRR `Q`**：反演目标；FDS 中由预设 HRRPUA 燃烧器精确给定（`HRRPUA = Q·1e6 / A_f`）。
- **对流 HRR `Q_c`**：FDS 实测 `CONVECTIVE HRR`（= 总 HRR − 辐射损失）。
- **预设 χ_r = 0.30**（`tunnel_config.CHI_R_PRESET`）；§1.8 用 FDS 实测 `Q_c/Q` 检验。

## 2. 关键纪律（§9 决策门）

- 若 `Q_c/Q` 随 Q/风速/尺寸**明显系统性变化** → 建立**对流比例修正关系**；
- **不得**在公式训练时使用仅 FDS 内部可得的对流 HRR，而在工程反演时默认其已知。
  （即：闭合公式训练阶段若用到对流 HRR，须保证工程端可由总 HRR + χ_r(或修正关系)得到。）

## 3. 执行

```
# 选覆盖 Q/风速/尺寸的代表工况（开发集或先导），读各自 _devc.csv 的 HRR_tot/HRR_conv
python3 src/check_convection_ratio.py \
  --rundir fds_cases --chids gsA_m gsB_m gsC_m ... \
  --t0 <t0> --t1 <t1> --outdir results/hrr
```

脚本对列名做模糊匹配（兼容不同 FDS 版本）；若 `CONVECTIVE HRR` 量名缺失，
按 `MODEL_SETTINGS.md §6` 第 2 条调整 `tunnel_config.QUANTITY_HRR_CONV`，
或由 `Q_c = Q − 辐射损失` 推算（辐射损失可由壁面 + 开口辐射通量设备得到）。

## 4. 检查内容

1. 准稳态窗口内 `Q_tot` 是否≈预设 Q（验证燃烧器 HRRPUA 设置正确）；
2. `χ_r_realized = 1 − Q_c/Q` 在各工况的取值与极差；
3. `χ_r_realized` 是否随 Q、U、Df 系统性变化（绘图观察）。
