# §1.8 火源辐射与对流比例检查

> 反演目标为总 HRR `Q`；温度模型使用火源对流功率 `Q_c,source=(1-χ_r)Q`。检查由 `src/check_convection_ratio.py` 读取 FDS `_hrr.csv` 完成。
> 本轮数据的派生清单按日志记录为 FDS 6.9.1；不得与 6.10.1 短试算混写。

## 1. 定义

FDS `_hrr.csv` 的符号约定下，`Q_RADI` 通常为负，表示辐射能量损失：

```text
χ_r = -Q_RADI / HRR
Q_c,source = HRR + Q_RADI
```

- `HRR`：FDS 实际总热释放率，正式窗口内用于核验预设 Q。
- `Q_RADI`：辐射损失项。
- `Q_c,source`：供经验温度模型使用的火源对流 HRR。
- `_hrr.csv Q_CONV`：整个计算域能量收支中的对流项，不得直接当作 `Q_c,source`。
- 项目不生成 `CONVECTIVE HRR` DEVC；FDS 6.10.1 不识别该量名。

燃烧器 `HRRPUA` 由吸附到网格后的离散面积计算，单位为 kW/m²。即使输入满足 `HRRPUA×A_discrete=Q[kW]`，正式功率仍须在约 `3×TAU_Q` 后并进入准稳态时，用 `HRR` 或 `HRR_tot` 时间平均核验。

## 2. 执行

```bash
python src/check_convection_ratio.py \
  --rundir 03_网格敏感性/runs \
  --chids gsA_c gsA_m gsA_f gsB_c gsB_m gsB_f gsC_c gsC_m gsC_f \
  --cases-csv 03_网格敏感性/grid_sensitivity_cases.csv \
  --steady-windows 03_网格敏感性/analysis/steady/steady_windows.csv \
  --outdir 03_网格敏感性/analysis/convection_ratio
```

前置条件：输入含 `DT_HRR=1.0`，每个工况已产生 `<chid>_hrr.csv`，文件中存在 `HRR` 和 `Q_RADI`。脚本读取 CSV 单位行并统一为 kW。

## 3. 检查与决策门

1. 准稳态窗口 `Q_tot` 是否接近目标 Q；斜坡期间数据不参与功率闭合结论。
2. 比较各 Q/U/Df 工况的 `χ_r_realized`、极差和趋势。
3. 若 `χ_r` 随 Q、风速或尺寸存在系统性变化，则建立 `χ_r(Q,U,Df)` 修正关系；否则可采用经数据支持的固定值。
4. 不得在公式训练时使用仅 FDS 内部可得的对流功率，却在工程反演端默认该量已知；工程端必须从总 HRR 与固定/修正后的 χ_r 获得。

## 5. 决策

- [x] `χ_r_realized` 是否稳定：**否**，极差超过 0.05。
- [x] 是否需要修正接口：**是**；后续闭合须预留 `χ_r(Q,U,D_f)`。
- [ ] 修正关系是否已定标：否。当前 A/B/C 中 Q、U、D_f 同时变化，只有 3 个
  工作网格点，不能区分各变量作用；须由阶段三开发工况定标和交叉验证。
- [ ] 论文工程反演口径：最终必须从总 HRR 与固定/修正后的 `χ_r` 得到
  `Q_c,source`，不得把 FDS 内部 `Q_RADI` 当作现场已知输入。

当前可将 0.30 作为生成与初始求解参考值，但不能把它写成已验证的全范围常数。
