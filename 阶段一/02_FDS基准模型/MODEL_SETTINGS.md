# §1.2 FDS 基准模型 · 完整模型设置说明（可复现记录）

> 论文中须完整记录以下设置以保证可复现。本文件随生产参数确定持续更新。
> 所有几何/物理默认值集中于 `src/tunnel_config.py`；FDS 输入由 `src/generate_fds_case.py` 生成。

## 1. 隧道几何（全局符号表一致）

| 项 | 值 | 备注 |
|---|---|---|
| 隧道高度 H | 5 m | 固定 |
| 隧道宽度 W | 10 m | 固定 |
| 隧道长度 L | 100 m | **实施.md 基准**；较理论研究方案.docx 的 250~300 m 显著缩短 → §1.4 生产前必查 |
| 洞口位置 | x=0、x=100 m | 纵向两端 OPEN（或入口 INLET） |
| 火源位置（主体闭合） | x≈50 m | 距两洞口各 10H；偏移工况见 §3.5 |
| 洞口缓冲 | 向内 ≥3H（≈15 m） | 火源/测量不得越界 |
| 均匀测量区 | x∈[15, 85] | 跨度 70 m≈14H，火源上下游各约 7H |

坐标系：x 沿纵长 [0,L]；y 横跨 [0,W]；z 自地面 [0,H]。火源居中于 y=W/2。

## 2. 固定模型参数

| 项 | 值 | 备注 |
|---|---|---|
| 环境温度 T_0 | 20 °C (293.15 K) | 固定 |
| 环境压力 P | 101325 Pa | 固定 |
| 壁面材料 | 混凝土衬砌 | ρ=2300, k=1.4, cp=880, ε=0.9, 厚 0.20 m |
| 燃料 | 正庚烷 n-heptane, SIMPLE_CHEMISTRY | soot_yield=0.037, CO_yield=0.010；池火替代物，碳烟适中便于实现合理 χ_r |
| 辐射模型 | FDS 有限体积法（默认角度数） | 默认开启 |
| 湍流模型 | LES（SIMULATION_MODE='LES'） | 浮力修正默认 |
| 火源建模 | 预设 HRRPUA 燃烧器 | 用 HRRPUA 精确控制总功率 Q；A_f=πD_f²/4，方形铺设 |
| 火源斜坡 | TAU=10 s | 避免冲击式启动 |
| 纵向通风 | 入口 x=0 施加速度 VEL（+x 方向），出口 x=L OPEN | VEL 约定：负值将气流推入域内；见 §6 验证项 |
| 测点高度 | 顶棚下方 0.10H（z=4.5 m） | 0.05H~0.10H 区间内取；§1.3 核查近壁稳定性 |
| 预设 χ_r | 0.30 | §1.8 用 FDS 实测 Q_c/Q 检验 |
| FDS 版本 | （运行平台填写） | 建议 FDS 6.7.x+ |
| 计算平台 | （建议 Linux/HPC + MPI） | 见 README 平台说明 |

## 3. 网格（§1.3 待收敛性确认定稿）

| 档 | dx | 单元数 (100m) | 用途 |
|---|---|---|---|
| 粗 | 0.5 m | 200×20×10 = 40,000 | 网格敏感性下界 |
| 中 | 0.25 m | 400×40×20 = 320,000 | **候选生产网格**（3 代表工况纳入 68 组 DB） |
| 细 | 0.125 m | 800×80×40 = 2,560,000 | 收敛性参考（高功率下计算量大） |

- 网格准则：`D*/δx ≈ 4~10`，`D*=(Q/(ρ_0 c_p T_0 √g))^{2/5}`。
- 决策门：最终网格依核心目标量(ΔT_p,x_p,κ_u,κ_d)是否收敛，而非单一尺度指标。
- 若高功率下 0.25 m 仍偏粗，可在火源附近嵌套加密（多 mesh）；本研究默认均匀单 mesh 以保证敏感性对比清晰。

## 4. 测点与输出（详见 `07_温度测点与输出规范/输出变量与频率规范.md`）

- 顶棚中心线 20~30 个虚拟测点（密集，火源区 0.5H、远场 H）；稀疏 4/8/12/16 由后处理抽取。
- 输出：顶棚气体温度、顶棚纵向速度、HRR(总/对流)、壁面净热通量、切片(中心纵剖面 + 多横截面)、边界场。
- 频率：DEVC=1 Hz；SLCF=5 s；BNDF=10 s；三维场降频或仅必要时段输出（控量）。

## 5. 温度变量纪律

主体研究只用**顶棚中心线下方固定高度气体温度**；不混用 FDS 气体单元温度、热电偶响应温度、
横截面平均烟层温度、壁面温度。外部试验若仅热电偶温度，须用响应模型或误差讨论说明差异。
测点高度确定后，所有 FDS 工况、解析模型、反演、网络统一采用。

## 6. 首次运行必查项（平台切换后首批执行）

> 以下为生成器使用广泛关键字但仍建议在目标 FDS 版本上首次启动时验证的点：
>
> **单位口径（§1.7 选项 B）**：`&DEVC` 不写 `UNITS`，devc.csv 输出默认 SI（温度 K、HRR W、热通量 W/m²、速度 m/s）；分析脚本经 `fds_io.normalize_units` 按 units 列归一为 °C/kW/kW·m⁻²，对旧 run（°C/kW）向后兼容。

1. **入口风向**：取一短时试算（T_END≈5 s），用中心纵剖面速度切片确认 x=0 入口气流方向为 +x；
   若反向，将 `tunnel_config` 中入口 `VEL` 符号取反（见 `generate_fds_case._fmt_surf_inlet`）。
2. **HRR 量名/统计量**：若 FDS 报未知量名，按版本调整 `tunnel_config` 中
   `QUANTITY_HRR_TOTAL / QUANTITY_HRR_CONV / STAT_VOLUME_INTEGRATION`；
   `check_convection_ratio.py` 对列名做模糊匹配作为兜底（详见 §1.8 报告）。
3. **壁面表面指派**：确认地面/顶棚/侧墙已应用混凝土 `WALL` 表面（FDS 以 &VENT 指派边界面材料）。
4. **燃烧器 HRRPUA**：核验 `HRRPUA = Q·1e6 / A_f` 与预设 Q 一致（看 `_devc.csv` 中 HRR_tot 稳态均值）。**§1.7 选项 B 下 `&DEVC` 不写 UNITS，HRR_tot 单位为 W（默认 SI）**，故稳态均值 ≈ Q[MW]×1e6（如 40 MW→4.0e7 W）；分析脚本经 `fds_io.normalize_units` 按 units 列归一为 kW。
5. **测点高度**：在所选网格上确认 z=4.5 m 距顶棚 ≥2 个网格、近壁温度稳定；否则在 0.05H~0.10H 内调整。
6. **燃料/反应**：确认 FDS 识别 `FUEL='n-HEPTANE'`（预定义物种名，大小写不敏感）；
   若该版本报未知物种，改 `tunnel_config.FUEL_NAME` 为 `'N-HEPTANE'`/`'PROPANE'`/`'METHANE'`。
   燃料仅影响 χ_r 与碳烟；最终以 §1.8 实测 χ_r 为准（可换更易产碳烟的燃料以提升 χ_r）。
