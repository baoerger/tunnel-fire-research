## 3. 是否需要换平台？—— **是，需要切换到 Linux/HPC 平台执行 FDS 计算**

原因（本机实测）：
1. 本机 `python` 仅为 Windows Store 占位（`python --version` 无输出，无实际解释器）；
   `pip`、`numpy` 均不可用 → 无法在本机运行分析脚本或绘图。
2. 本机未安装 FDS、`mpiexec`、`conda` → 无法执行任何 FDS 计算。
3. FDS 在 Linux + MPI 下效率最高、并行稳定；批量 81~84 次计算（含 0.125 m 细网格，
   单工况 2.56M 单元、壁钟 6~15 h）不适合 Windows 单机。

**建议平台**：
- Linux 集群（Slurm/队列），≥8 核/节点、≥32 GB 内存/工况（细网格上调）、共享存储 ≥2 TB；
- 软件栈：FDS 6.7.x+、MPI（OpenMPI/MPICH）、Python 3 + numpy + matplotlib。
- 已提供 `src/run_slurm_template.sh`（Slurm array）与 `src/run_batch.sh`（本地/单节点批量）。

**换平台后的第一步**：
1. （语法自检，本机无 Python 无法预检）`python3 -m py_compile src/*.py` 应无错；
2. `module load fds` 或设置 `FDS_BIN`；
3. 生成工况：`python3 src/generate_fds_case.py --csv 03_网格敏感性/grid_sensitivity_cases.csv --outdir fds_cases`；
4. 跑一例短试算（如 `tunnel_benchmark.fds` 截短 T_END=5 s）按 `MODEL_SETTINGS.md §6` 验证六项必查；
5. 通过后批量提交网格敏感性 9 工况 → 准稳态检测 → 时间平均 → 网格/边界/对流比例分析。
