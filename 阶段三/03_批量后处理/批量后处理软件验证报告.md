# 批量后处理软件验证报告

状态：**软件通路完成；真实数据库、准稳态窗口和 `Delta T_noise` 等待正式 FDS。**

`src/batch_postprocess.py` 按以下顺序处理选定子集：

1. 调用阶段一轻量检查，只有 `PASS` 自动继续；`REVIEW` 必须人工检查，`FAIL` 标记修复/重算；
2. 综合 HRR 波动、最大/代表温度趋势、回流长度趋势和可用焓流判据识别准稳态；
3. 对 PASS 窗口执行时间平均和自相关块长 Bootstrap；
4. 记录稳态窗口内逐传感器时间标准差，并按 `parent_chid` 汇总重复种子均值离散；
5. 写出 `database_completion.csv`，区分等待回传、需复核、需延长/重算、后处理失败和待显式采用。
